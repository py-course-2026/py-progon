**[Б1]** Денис, спасибо за вопросы — половину мы между собой и не обсуждали. Отвечаю по порядку.

**[Б2]** «Мгновенно» — это чтобы студент не ждал до следующего дня. Минута — уже хорошо. В пятницу вечером пусть дольше, но студент должен видеть, что его работа стоит в очереди и какая она по счёту, — иначе он отправит её ещё десять раз.

**[Б3]** Про тесты. Студент видит название теста и сообщение об ошибке, но не входные данные. Часть тестов преподаватель может сделать открытыми — такие студент видит целиком, вместе с данными.

**[Б4]** В ведомость идёт лучший балл из всех попыток. Попытка после срока засчитывается с коэффициентом 0,5. Если преподаватель продлил срок студенту по уважительной причине — это персональный новый срок: одному студенту по одному заданию, и до него попытки идут без снижения.

**[Б5]** Ведомость: ФИО, группа, баллы по каждому заданию в порядке заданий, итоговая сумма. Для учебной части — файл, который открывается в Excel двойным щелчком, без мастеров импорта.

**[Б6]** Сервер у колледжа есть: Linux, Ubuntu 24.04, 8 ядер, 16 ГБ памяти. Студенты и преподаватели работают через браузер — из класса и из дома.

**[Б7]** Список студентов по группам даёт учебная часть в начале семестра, в Excel. Логины и пароли студентам выдаём мы сами, регистрация не нужна.

**[Б8]** По срокам: хотим попробовать на одной группе через шесть недель, а со второй половины семестра — на всех двенадцати. Документацию — руководство для преподавателя и для студента — к запуску на всех группах.
