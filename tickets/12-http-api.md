# PRG-12. HTTP API

**Автор:** Денис Юрченко, тимлид · **Неделя:** 12

Коллеги, «Прогон» умеет всё, что нужно колледжу, — но только из терминала на сервере. Ирина Павловна напоминает: студенты и преподаватели работают через браузер, из класса и из дома [А9, Б6]. Страницы сделает фронтенд-разработчик — ему нужен от нас HTTP API. Весной вы писали API на FastAPI по образцу; теперь — по нашему ТЗ, с безопасностью и тестами.

## Что сделать — `progon/api.py`

Зависимости: `uv add fastapi uvicorn` и `uv add --dev httpx` (нужен тестовому клиенту FastAPI). Закоммитьте `pyproject.toml` и `uv.lock`.

### 1. Фабрика приложения

`create_app(settings) -> FastAPI` — приложение собирается из настроек, а не читает их при импорте: так тесты создают приложение со своей базой и своим курсом во временной папке. `Settings` — неизменяемый: `course` (файл курса JSON), `db` (база SQLite), `tests_root` (папка с тестами заданий: `tests_root/<задание>/`), `api_key`. `settings_from_env()` — те же настройки из переменных `PROGON_COURSE`, `PROGON_DB`, `PROGON_TESTS`, `PROGON_API_KEY`.

### 2. Доступ

- `GET /health` → `{"status": "ok", "version": "…"}` — **без** ключа, для мониторинга.
- Всё остальное — только с заголовком `X-API-Key: <api_key>`, иначе 401. Проверка ключа — зависимость FastAPI (`Depends`), общая для всех ручек (`APIRouter(dependencies=[…])`); сравнение — `hmac.compare_digest`.

### 3. Ручки

- `GET /tasks` → `[{"name", "deadline", "max_score"}]` в порядке заданий курса.
- `POST /submissions` с телом `{"login", "task", "files": {"calc.py": "текст модуля"}}` → **201** и `{"id", "status", "passed", "total", "score", "failed": [{"test", "message"}]}`. Решение записывается во временную папку, прогоняется `run_tests` с пределом времени задания (`Task.timeout`), попытка сохраняется в базу (`Storage.save_run`), балл — `max_score × прошло / всего`, два знака. Студент видит в `failed` название теста и первую строку сообщения — не больше [Б3].
- `GET /students/{login}/history` → попытки студента из базы.
- `GET /gradebook` → `{"tasks": [...], "rows": [{"name", "group", "scores": [...], "total"}]}` — ведомость по попыткам **из базы**, с учётом сроков и продлений из файла курса.

### 4. Проверка входа — это безопасность

- Имена файлов решения — только модули в корне: `[A-Za-z_][A-Za-z0-9_]*.py`. `../calc.py`, `sub/calc.py`, `calc.txt` — 422: иначе решение запишет файл куда угодно на сервере.
- Решение — не пустое и не больше 1 МБ всего (ТЗ, 4.3) — 422.
- Неизвестное задание или студент — 404.
- Всё это — моделью Pydantic с валидатором (`field_validator`), а не проверками внутри ручки.

### 5. Запуск и тесты

- `progon serve [--host] [--port]` — `uvicorn.run(create_app(settings_from_env()), …)`. Откройте `/docs` — FastAPI сам описал ваш API по моделям.
- `tests/test_api.py` — ваши тесты через `fastapi.testclient.TestClient`: сдача решения, 401 без ключа, 422 на опасное имя файла.
- `api.py` — в `docs/DESCRIPTION.md`.

## Критерии готовности

- `make check-api12` и `make check-sub12` зелёные, старые — тоже.
- PR `prg-12` в `main`. В описании: какие атаки на сервер колледжа закрывают проверка имён файлов и `compare_digest`, и почему `create_app` лучше глобального `app = FastAPI()`, настроенного при импорте.
