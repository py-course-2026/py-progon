У нас есть история прошлого семестра — попробуем.

## Что сделать

Зависимости: `uv add pandas matplotlib scikit-learn`. У pandas и scikit-learn нет аннотаций типов — чтобы `mypy --strict` не падал на их импорте, добавьте в `pyproject.toml`:

```toml
[[tool.mypy.overrides]]
module = ["pandas.*", "sklearn.*", "joblib.*"]
ignore_missing_imports = true
```

### 1. График — `progon/analytics.py`, `progon chart ФАЙЛ --out PNG`

`plot_tasks(course, path) -> Figure`: столбцы — средний лучший балл по заданиям (из `task_stats`, PRG-9), над столбцами — доля опозданий; заголовок «Средний лучший балл по заданиям», подписи по оси X — имена заданий по порядку. Картинка — в PNG, без окна: `matplotlib.use("Agg")`.

### 2. Модель риска — `progon/predict.py`

История — `checks/ml13/train.csv` (обучение) и `checks/ml13/test.csv` (отложенная выборка): студент и задание, признаки первых суток — `first_score` (балл первой попытки), `attempts_day1` (попыток в первые сутки), `hours_before` (за сколько часов до срока первая попытка), `prev_best` (лучший балл за прошлое задание) — и цель `at_risk` (1, если итоговый балл меньше 6).

- `load_history(path)` → признаки (`DataFrame`) и цель; нет файла или столбцов — `InputError`.
- `train(path)` → обученная модель. Начните с простого: стандартизация признаков и логистическая регрессия (`make_pipeline(StandardScaler(), LogisticRegression())`).
- `evaluate(model, path)` → `{"accuracy", "baseline"}` на **отложенной** выборке; `baseline` — доля верных у модели «как большинство» (`DummyClassifier(strategy="most_frequent")`). Модель, которая не обгоняет её, бесполезна.
- `risk(model, features)` → вероятность от 0 до 1, что студент не наберёт 6 баллов.
- `save(model, path)` и `load(path)`.
- `progon model ИСТОРИЯ.csv --test ОТЛОЖЕННАЯ.csv --out МОДЕЛЬ` печатает `Доля верных: 0.79, у базовой модели: 0.69` и сохраняет модель.

### 3. `POST /risk` в API

`Settings` получает необязательное поле `model` — путь к модели. `POST /risk` с телом `{"first_score", "attempts_day1", "hours_before", "prev_best"}` (баллы — от 0 до 10, иначе 422) → `{"risk": 0.83}`; модели нет в настройках — 503.

Модель предсказывает про людей.
