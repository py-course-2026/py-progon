# PRG-6. Релиз 0.1 к пилоту

**Автор:** Денис Юрченко, тимлид · **Неделя:** 6

Коллеги, шесть недель назад Ирина Павловна попросила пилот на одной группе [Б8]. Пора. Релиз — это не «код работает у меня»: это версия, которую можно назвать, поставить на сервер колледжа одной командой и объяснить преподавателю без нас. Кода в этом тикете мало, всё остальное — то, что отличает программу от продукта.

## Что сделать

### 1. `progon check ФАЙЛ`

Перед тем как грузить файл курса, преподаватель хочет убедиться, что в нём нет ошибок:

```text
Заданий: 3, студентов: 3, попыток: 7, продлений: 1
Попыток после срока: 2
Курс в порядке.
```

«После срока» — с учётом персональных продлений. Ошибка в данных — как у `gradebook`: `progon: ошибка: …`, код 1, в stdout — ничего.

### 2. Журнал изменений — `CHANGELOG.md`

По формату [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/): заголовок выпуска `## [0.1.0] — ГГГГ-ММ-ДД`, под ним — что добавлено, пунктами, человеческим языком: не «рефакторинг cli.py», а «ведомость для Excel открывается двойным щелчком». Версия выпуска совпадает с версией в `pyproject.toml`.

### 3. Руководство — `docs/USER_GUIDE.md`

Для преподавателя, не для разработчика. Разделы: **Назначение**, **Установка**, **Команды** (с примерами каждой команды в блоках кода), **Сообщения об ошибках** (что означает каждое и что сделать). Полное оформление по ГОСТ 19 — на неделе 7, сейчас — чтобы пилотная группа могла работать.

### 4. Пакет

`uv build` собирает **wheel** — архив, который ставится на сервер колледжа одной командой `uv tool install progon-0.1.0-py3-none-any.whl` без исходников и без git. Проверьте, что в нём весь пакет `progon` и нет ничего лишнего (тестов, проверок, документов), а команда `progon` прописана в точках входа. Wheel — это zip: откройте его и посмотрите сами.

### 5. Выпуск

Когда всё зелёное: слейте PR, поставьте тег `git tag v0.1.0` и отправьте его — `git push origin v0.1.0`. Тег — это имя, по которому через месяц можно будет найти ровно тот код, что стоит на сервере.

## Критерии готовности

- `make check-rel6` и `make check-pkg6` зелёные, **все** старые — тоже: релиз с красными проверками не выпускаем.
- PR `prg-6` в `main` на ревью у доски: покажите ведомость, отчёт и `progon check` на своих данных.
- В описании PR: почему версия 0.1.0, а не 1.0.0, и что изменится в номере версии, если в следующем выпуске поменяется формат файла курса.
